## 1. Install the SDK

<CodeGroup>
```bash npm
npm install @fetchbrain.com/sdk
```

```bash yarn
yarn add @fetchbrain.com/sdk
```

```bash pnpm
pnpm add @fetchbrain.com/sdk
```

</CodeGroup>

## 2. Get Your API Key

1. Sign up at [fetchbrain.com](https://fetchbrain.com/signup)
2. Go to [Dashboard → API Keys](https://fetchbrain.com/dashboard/keys)
3. Create a new API key

## 3. Wrap Your Crawler

```typescript
import { FetchBrain } from "@fetchbrain.com/sdk";
import { CheerioCrawler } from "crawlee";

const crawler = FetchBrain.enhance(
  new CheerioCrawler({
    requestHandler: async ({ $, request, pushData }) => {
      // This only runs when the brain needs to learn (unknown request)
      const data = {
        title: $("h1").text(),
        price: $(".price").text(),
      };
      await pushData(data);
    },
  }),
  {
    apiKey: process.env.FETCHBRAIN_API_KEY,
    memory: "recent",
  }
);

await crawler.run(urls);
```

## 4. Run Your Scraper

```bash
FETCHBRAIN_API_KEY=fb_live_your_key npx ts-node scraper.ts
```

That's it! 🎉 Your scraper now:

- ✅ Recalls known requests before each fetch
- ✅ Skips HTTP when the brain already knows the data
- ✅ Automatically teaches the brain on new requests, for free

## Ask a question across everything learned

Once a few runs have taught the brain, you can query across all of it —
not just one request at a time:

```typescript
import { FetchBrainClient } from "@fetchbrain.com/sdk";

const client = new FetchBrainClient({ apiKey: process.env.FETCHBRAIN_API_KEY });
const res = await client.ask("which products are under $20?", { answer: true });

console.log(res.answer);
console.log(res.sources);
```
