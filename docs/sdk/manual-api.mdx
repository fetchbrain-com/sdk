## Overview

For custom integrations or non-Crawlee scrapers, use the FetchBrain class directly.
The class exposes URL-based convenience methods that build the underlying
batch wire (`{ items: [{ ref, request }] }` for recall, `{ entries: [{ request, data }] }`
for learn) for you.

<Note>
  Identity is derived **server-side** from `(method, normalized url, uniqueKey)`.
  The `FetchBrain.recall({ url })` / `learn({ url, data })` helpers key by URL. If
  you scrape several distinct resources behind one URL (POST or GraphQL
  endpoints), call the lower-level client with a `uniqueKey` so each is stored
  separately — see [the Recall endpoint](/docs/api-reference/endpoints/recall).
</Note>

## Basic Usage

```typescript
import { FetchBrain } from "@fetchbrain.com/sdk";

const brain = new FetchBrain({
  apiKey: process.env.FETCHBRAIN_API_KEY,
  memory: "recent",
});

// Check if the brain knows a URL
const result = await brain.recall({ url: "https://example.com/product/123" });

if (result.known) {
  console.log("Brain knows:", result.data);
} else {
  // Fetch and teach
  const data = await scrapeUrl("https://example.com/product/123");
  await brain.learn({ url: "https://example.com/product/123", data });
}
```

## Methods

### `recall(options)`

Check if the brain knows a URL.

```typescript
const result = await brain.recall({
  url: "https://example.com/product/123",
  memory: "recent", // Optional, overrides default
});
```

**Returns:**

```typescript
{
  known: boolean;
  data?: object; // present when known
}
```

### `learn(options)`

Teach the brain about a URL.

```typescript
await brain.learn({
  url: "https://example.com/product/123",
  data: { title: "Product Name", price: 99.99 },
});
```

### `stats()`

Get your usage statistics.

```typescript
const stats = await brain.stats();
console.log(stats);
// {
//   queries: 46753,
//   known: 45230,
//   recallRate: 0.97,
//   learned: 1523,
//   period: "2026-06"
// }
```

## Asking Questions

`ask()` is available on the lower-level `FetchBrainClient` — either the one
attached to an enhanced crawler (`crawler.fetchBrain`) or one you construct
directly for standalone use:

```typescript
import { FetchBrainClient } from "@fetchbrain.com/sdk";

const client = new FetchBrainClient({
  apiKey: process.env.FETCHBRAIN_API_KEY!,
});

const answer = await client.ask("what products are under $20?", { limit: 5 });
console.log(answer.sources);
```

## Full Example

```typescript
import { FetchBrain } from "@fetchbrain.com/sdk";

async function main() {
  const brain = new FetchBrain({
    apiKey: process.env.FETCHBRAIN_API_KEY!,
  });

  const urls = [
    "https://example.com/product/1",
    "https://example.com/product/2",
    "https://example.com/product/3",
  ];

  for (const url of urls) {
    const result = await brain.recall({ url });

    if (result.known) {
      console.log(`✓ Brain knows ${url}:`, result.data);
    } else {
      console.log(`→ Fetching ${url}...`);

      // Your custom fetch logic
      const response = await fetch(url);
      const html = await response.text();
      const data = parseProduct(html);

      // Teach the brain
      await brain.learn({ url, data });
      console.log(`✓ Taught the brain about ${url}`);
    }
  }

  // Check stats
  const stats = await brain.stats();
  console.log("Recall rate:", stats.recallRate);
}
```
