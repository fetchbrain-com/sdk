title: Brain Context
description: "Access brain data directly in your request handler"
---

## Overview

When using `FetchBrain.enhance()`, your request handler receives a `brain` property in the context with information about what the brain knows.

## Usage

```typescript
const crawler = FetchBrain.enhance(
  new CheerioCrawler({
    requestHandler: async ({ $, request, brain, pushData }) => {
      // Check if the brain already knows this page
      if (brain?.known) {
        console.log("Brain knows this page");

        // Option 1: Use brain data directly (skip scraping)
        await brain.use();
        return;

        // Option 2: Compare brain data with scraped data
        // const scraped = { title: $('h1').text() };
        // console.log('Brain:', brain.data, 'Scraped:', scraped);
      }

      // Scrape normally if the brain doesn't know
      const data = { title: $("h1").text() };
      await pushData(data);
    },
  }),
  { apiKey: "your-api-key", alwaysRun: true }
);
```

<Note>
  By default, when the brain knows a page the handler is skipped entirely — so
  the only time your handler runs and can read `brain.known === true` is when
  you opt in with `alwaysRun` (either `true`, or a label list that matches this
  request). Without `alwaysRun`, the handler only runs for pages the brain does
  **not** know.
</Note>

## Brain Context Properties

<ParamField body="known" type="boolean">
  Whether the brain knows this URL
</ParamField>

<ParamField body="data" type="object">
  The brain's known data (if known)
</ParamField>

<ParamField body="use" type="() => Promise<void>">
  Helper function to push brain data and skip scraping
</ParamField>

## Use Cases

### Skip scraping when the brain knows

```typescript
if (brain?.known) {
  await brain.use();
  return;
}
```

### Verify brain data

```typescript
if (brain?.known) {
  const scraped = { title: $("h1").text() };
  if (scraped.title !== brain.data.title) {
    console.log("Data changed! Teaching the brain...");
    await pushData(scraped);
  }
}
```

### Conditional scraping based on memory depth

```typescript
// Use a narrower memory window for time-sensitive pages
const crawler = FetchBrain.enhance(crawler, {
  memory: "fresh",
});
```

```typescript
if (brain?.known) {
  // Brain knows within the configured memory window, trust it
  await brain.use();
} else {
  // Unknown, scrape fresh
  await pushData({ title: $("h1").text() });
}
```
